## [0.0.1] — Initial Release

This is an early preview, fresh out of the oven. Things may be hot, edges may be sharp, and there are zero guarantees. Use at your own enthusiasm.

What's inside:
- Native VS Code chat panel with streaming responses, thinking blocks, and tool execution display
- 17 VS Code bridge tools (diagnostics, symbols, references, code actions, formatting, etc.)
- Model picker, thinking level picker, slash command picker, file reference picker
- Session management (fork, export, resume, compaction)
- `/login` API key setup, auto-compaction and auto-retry toggles
- Activity bar icon with session tree view
